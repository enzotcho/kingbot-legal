# Privacy Policy — KingBot

**Last updated:** 09-02-2026

KingBot is a Discord bot created to help players of *Kingshot* with calculators and gift code features.

## 1) Data we collect
KingBot may store the following data:

### Discord data
- **User ID** (Discord user identifier)
- **Guild ID** used to save message customization from the Events section on a server.
- **Language preference (FR/EN)** used for translations and messages in Discord

### Kingshot-related data (provided by the user)
- **Kingshot Player IDs** (main / farm)  
  Used to redeem gift codes and link actions to the correct account.
- **Kingshot profile data** (fetched to help the user verify the account):  
  **nickname**, **region**, **center level**

### Gift codes & redemption results
- Gift codes added by users: **code**, optional **date**, optional **note**
- Redemption results per account/code: status such as  
  **success**, **already**, **expired**, **server_busy**, plus the **popup/message** returned by the redemption process.

### Ticket system data
- Ticket content and metadata: **message content**, **author**, **status**  
  Used for support, bug reports, improvement requests, and **data deletion requests**.

## 2) Why we collect this data (purposes)
We use the data to:
- Provide bot features (calculators, menus, translations)
- Link Kingshot IDs to the correct Discord user
- Display profile information so users can verify their account
- Manage gift codes and show redemption outcomes
- Provide support through the ticket system and respond to requests
- Allow configuration by server

## 3) Data sharing
KingBot does **not** sell personal data.  
Data is not shared with third parties except:
- Discord (as part of using the Discord platform)
- The services required to run the bot (hosting / infrastructure)

## 4) Data retention
We keep data only as long as needed to provide the service:
- **Kingshot IDs / profiles / redemption results**: stored until the user requests deletion or stops using the bot for a long period.
- **Tickets**: stored to handle support requests and history, then removed when no longer needed.
- **Guild ID** : as long as the bot is present on the server

If you want a stricter policy, you can request deletion anytime via the ticket system.

## 5) Your rights (access / deletion)
You can request:
- Access to the data stored about you
- Correction of incorrect data
- Deletion of your data

**How to request:** open a ticket directly in the bot (Support / Ticket).  
We may ask you to confirm ownership of the Discord account before deleting data.

## 6) Security
We take reasonable measures to protect stored data (access control, limited access to databases, etc.).  
However, no system is 100% secure.

## 7) Contact
Support and privacy requests are handled **via the bot’s ticket system**.

# Politique de confidentialité — KingBot

**Dernière mise à jour :** 09-02-2026

KingBot est un bot Discord conçu pour aider les joueurs de *Kingshot* via des calculateurs et la gestion de codes cadeaux.

## 1) Données collectées
KingBot peut stocker les données suivantes :

### Données Discord
- **User ID** (identifiant Discord)
- **Guild ID** utilisé pour enregistrer la personnalisation du message de la section Événements sur un serveur.
- **Langue (FR/EN)** utilisée pour les traductions et messages dans Discord

### Données Kingshot (fournies par l’utilisateur)
- **IDs joueur Kingshot** Utilisés pour appliquer les codes cadeaux et associer les actions au bon compte.
- **Données de profil Kingshot** (récupérées pour vérifier le compte) :  
  **pseudo (nickname)**, **région**, **niveau du centre (center level)**

### Codes cadeaux & résultats
- Codes cadeaux ajoutés : **code**, optionnel **date**, optionnel **note**
- Résultats de redemption par compte/code :  
  **success**, **already**, **expired**, **server_busy**, + le **message/popup** renvoyé pendant la validation.

### Données tickets (support)
- Contenu et métadonnées du ticket : **contenu**, **auteur**, **statut**  
  Utilisés pour le support, les remontées de bugs, les demandes d’amélioration et les **demandes de suppression de données**.

## 2) Pourquoi ces données (finalités)
Ces données servent à :
- Fournir les fonctionnalités du bot (menus, calculs, traductions)
- Associer un ID Kingshot à un utilisateur Discord
- Afficher le profil afin que l’utilisateur vérifie que c’est bien son compte
- Gérer les codes cadeaux et afficher les résultats
- Assurer le support via le système de tickets
- Permettre la configuration par serveur

## 3) Partage des données
KingBot ne vend **pas** de données personnelles.  
Les données ne sont pas partagées avec des tiers, sauf :
- Discord (plateforme utilisée)
- Les services nécessaires à l’hébergement et au fonctionnement du bot

## 4) Durée de conservation
Les données sont conservées uniquement le temps nécessaire :
- **IDs Kingshot / profils / résultats** : jusqu’à demande de suppression, ou après une longue période d’inactivité.
- **Tickets** : le temps de traiter la demande et conserver un historique utile, puis suppression lorsque ce n’est plus nécessaire.
- **Guild ID** : tant que le Bot est présent sur le serveur

Tu peux demander une suppression à tout moment via un ticket.

## 5) Tes droits (accès / suppression)
Tu peux demander :
- L’accès aux données te concernant
- La correction de données inexactes
- La suppression de tes données

**Comment faire :** ouvre un ticket via le bot (Support / Ticket).  
On peut te demander de confirmer que tu es propriétaire du compte Discord.

## 6) Sécurité
Nous appliquons des mesures raisonnables (contrôle d’accès, accès limité aux bases, etc.).  
Nous mettons en place des mesures de sécurité raisonnables. Malgré cela, aucun service en ligne ne peut garantir un risque zéro.

## 7) Contact
Le support et les demandes liées à la confidentialité se font **via le système de ticket du bot**.
