# Privacy Policy - KingBot

**Last updated:** 29-05-2026

KingBot is a Discord bot created to help players of *Kingshot* with calculators, account tools, community access management, alerts, kingdom tracking, KVK tools, and gift code features.

## 1) Data we collect
KingBot may store the following data:

### Discord data
- **User ID** (Discord user identifier)
- **Guild ID** used for server-related configuration and community access management
- **Channel ID / role ID / message ID** when needed for alerts, configuration, published messages, or role management
- **Language preference (FR/EN)** used for translations and messages in Discord
- **Guild membership state** for the official KingBot Community server when required to unlock specific features

### Kingshot-related data provided by the user
- **Kingshot Player IDs**:
  - **main ID**
  - **farm ID**
  - **farm2 ID**
  - **farm3 ID**
- **Kingshot profile data** used to help the user verify the linked account:
  - **nickname**
  - **region / kingdom**
  - **center level**
  - **profile image / center image** when available
  - **last update timestamp**

### Calculators and progression data
Depending on the feature used, KingBot may store calculator inputs or progression values, including:
- Academy and War Academy research levels selected by the user
- KVK planner inputs such as resources, speedups, hero shards, gear materials, pet materials, troop training or promotion values, and gathering speed values
- Other calculator inputs required to show progress, estimates, totals, or recommendations

### Kingdom tracking and KVK data
KingBot may store kingdom-related information, including:
- Kingdom number and opening date
- Kingdom follows selected by users
- Kingdom stage information, estimated stage dates, and manually validated stage dates
- KVK seasons and KVK match results
- Preparation winner, castle winner, preparation points, and related match metadata
- Contributor information when a user chooses to display their Kingshot nickname instead of being anonymous

### Gift codes, alerts, and redemption data
- Gift codes added by users: **code**, optional **added date**, optional **expiration date**
- Gift code alert configuration such as enabled/disabled state and target channel
- Redemption results per account/code: status such as **success**, **already**, **expired**, **server_busy**, plus the **popup/message** returned by the redemption process

### Ticket system and support data
- Ticket content and metadata: **message content**, **author**, **status**
- Used for support, bug reports, improvement requests, legal/privacy requests, and data deletion requests

### Extra ID management data
When a user leaves the official KingBot Community server, KingBot may temporarily store a scheduled cleanup state for **farm2** and **farm3** so those extra IDs can be removed later if the user does not return.

## 2) Why we collect this data
We use the data to:
- Provide bot features such as calculators, menus, translations, account tools, alerts, kingdom tracking, and KVK planning
- Link Kingshot IDs to the correct Discord user
- Display profile information so users can verify their account
- Store progress and inputs needed by calculators
- Manage gift codes, gift code alerts, and redemption outcomes
- Manage feature access depending on membership in the official KingBot Community server
- Provide kingdom information, KVK history, rankings, and stage estimates
- Provide support through the ticket system and respond to requests
- Allow server-related configuration
- Remove extra Kingshot IDs when a user no longer meets the conditions required to keep them

## 3) Data sharing
KingBot does **not** sell personal data.

Data is not shared with third parties except:
- Discord, as part of using the Discord platform
- The services required to run the bot, such as hosting and infrastructure
- External services or public data sources used to retrieve Kingshot-related information when a feature requires it

## 4) Data retention
We keep data only as long as needed to provide the service:
- **Kingshot IDs / profiles / redemption results**: stored until the user requests deletion or stops using the bot for a long period
- **Calculator progress and inputs**: stored until the user resets them, requests deletion, or no longer uses the bot for a long period
- **Kingdom data and KVK results**: may be kept as shared community data unless corrected, removed, or no longer needed
- **Extra IDs (`farm2` / `farm3`)**: may be removed automatically if the user leaves the official KingBot Community server and does not return within the configured delay
- **Tickets**: stored to handle support requests and history, then removed when no longer needed
- **Guild ID / channel ID / role ID / alert configuration**: stored only as long as needed for the related server features

You can request deletion anytime via the ticket system.

## 5) Your rights
You can request:
- Access to the data stored about you
- Correction of incorrect data
- Deletion of your personal data

**How to request:** open a ticket directly in the bot.
We may ask you to confirm ownership of the Discord account before deleting data.

## 6) Security
We take reasonable measures to protect stored data, such as access control and limited access to databases.
However, no system is 100% secure.

## 7) Contact
Support and privacy requests are handled **via the bot's ticket system**.

# Politique de confidentialité - KingBot

**Dernière mise à jour :** 29-05-2026

KingBot est un bot Discord conçu pour aider les joueurs de *Kingshot* avec des calculateurs, des outils de compte, la gestion d’accès communautaire, les alertes, le suivi des royaumes, les outils KVK et les codes cadeaux.

## 1) Données collectées
KingBot peut stocker les données suivantes :

### Données Discord
- **User ID** (identifiant Discord)
- **Guild ID** utilisé pour la configuration liée aux serveurs et la gestion d’accès communautaire
- **Channel ID / role ID / message ID** lorsque cela est nécessaire pour les alertes, la configuration, les messages publiés ou la gestion des rôles
- **Langue (FR/EN)** utilisée pour les traductions et les messages dans Discord
- **État d’appartenance au serveur** pour le serveur officiel KingBot Community lorsque certaines fonctionnalités en dépendent

### Données Kingshot fournies par l’utilisateur
- **IDs joueur Kingshot** :
  - **main ID**
  - **farm ID**
  - **farm2 ID**
  - **farm3 ID**
- **Données de profil Kingshot** utilisées pour aider l’utilisateur à vérifier le compte lié :
  - **pseudo**
  - **région / royaume**
  - **niveau du centre**
  - **image de profil / image du centre** quand disponible
  - **date de mise à jour**

### Calculateurs et données de progression
Selon la fonctionnalité utilisée, KingBot peut stocker des valeurs de progression ou des informations saisies dans les calculateurs, notamment :
- niveaux de recherche Académie et Académie de guerre sélectionnés par l’utilisateur
- données du calculateur KVK comme les ressources, accélérateurs, fragments de héros, matériaux d’équipement, matériaux d’animaux, valeurs d’entraînement ou de promotion de troupes et vitesses de collecte
- autres données nécessaires pour afficher une progression, des estimations, des totaux ou des recommandations

### Suivi des royaumes et données KVK
KingBot peut stocker des informations liées aux royaumes, notamment :
- numéro de royaume et date d’ouverture
- royaumes suivis par les utilisateurs
- étapes du royaume, dates estimées et dates validées manuellement
- saisons KVK et résultats de matchs KVK
- gagnant de la préparation, gagnant du château, points de préparation et métadonnées du match
- informations du contributeur lorsqu’un utilisateur choisit d’afficher son pseudo Kingshot au lieu d’être anonyme

### Codes cadeaux, alertes et données de récupération
- codes cadeaux ajoutés par les utilisateurs : **code**, **date d’ajout** optionnelle, **date d’expiration** optionnelle
- configuration des alertes codes cadeaux, comme l’état activé/désactivé et le salon cible
- résultats de récupération par compte/code : statuts comme **success**, **already**, **expired**, **server_busy**, ainsi que le **message/popup** renvoyé pendant la validation

### Tickets et support
- contenu et métadonnées du ticket : **contenu**, **auteur**, **statut**
- utilisés pour le support, les remontées de bugs, les demandes d’amélioration, les demandes légales/confidentialité et les demandes de suppression de données

### Données de gestion des IDs supplémentaires
Lorsqu’un utilisateur quitte le serveur officiel KingBot Community, KingBot peut stocker temporairement un état de suppression différée pour **farm2** et **farm3** afin de retirer plus tard ces IDs supplémentaires si l’utilisateur ne revient pas.

## 2) Pourquoi ces données sont collectées
Ces données servent à :
- fournir les fonctionnalités du bot : calculateurs, menus, traductions, outils de compte, alertes, suivi des royaumes et préparation KVK
- associer les IDs Kingshot au bon utilisateur Discord
- afficher les informations de profil afin que l’utilisateur vérifie son compte
- enregistrer les progressions et les données nécessaires aux calculateurs
- gérer les codes cadeaux, les alertes codes cadeaux et les résultats de récupération
- gérer l’accès à certaines fonctionnalités selon l’appartenance au serveur officiel KingBot Community
- fournir des informations sur les royaumes, l’historique KVK, les classements et les estimations d’étapes
- assurer le support via le système de tickets
- permettre la configuration liée aux serveurs
- supprimer les IDs Kingshot supplémentaires lorsqu’un utilisateur ne remplit plus les conditions nécessaires pour les conserver

## 3) Partage des données
KingBot ne vend **pas** de données personnelles.

Les données ne sont pas partagées avec des tiers, sauf :
- Discord, dans le cadre de l’utilisation de la plateforme Discord
- les services nécessaires à l’hébergement et au fonctionnement du bot
- les services externes ou sources publiques utilisés pour récupérer des informations liées à Kingshot lorsqu’une fonctionnalité en a besoin

## 4) Durée de conservation
Les données sont conservées uniquement le temps nécessaire :
- **IDs Kingshot / profils / résultats de récupération** : jusqu’à demande de suppression, ou après une longue période d’inactivité
- **progressions et données de calculateurs** : jusqu’à réinitialisation par l’utilisateur, demande de suppression, ou longue période d’inactivité
- **données de royaume et résultats KVK** : peuvent être conservés comme données communautaires partagées, sauf correction, suppression ou absence d’utilité
- **IDs supplémentaires (`farm2` / `farm3`)** : peuvent être supprimés automatiquement si l’utilisateur quitte le serveur officiel KingBot Community et ne revient pas dans le délai configuré
- **tickets** : le temps de traiter la demande et conserver un historique utile, puis suppression lorsque ce n’est plus nécessaire
- **Guild ID / channel ID / role ID / configuration d’alertes** : uniquement le temps nécessaire aux fonctionnalités concernées

Tu peux demander la suppression à tout moment via le système de ticket.

## 5) Tes droits
Tu peux demander :
- l’accès aux données te concernant
- la correction de données inexactes
- la suppression de tes données personnelles

**Comment faire :** ouvre un ticket directement via le bot.
On peut te demander de confirmer que tu es propriétaire du compte Discord avant de supprimer des données.

## 6) Sécurité
Nous appliquons des mesures raisonnables pour protéger les données stockées, comme le contrôle d’accès et l’accès limité aux bases de données.
Cependant, aucun système n’est sécurisé à 100%.

## 7) Contact
Le support et les demandes liées à la confidentialité se font **via le système de ticket du bot**.
