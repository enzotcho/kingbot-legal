# Privacy Policy - KingBot

**Last updated:** 23-03-2026

KingBot is a Discord bot created to help players of *Kingshot* with calculators, account tools, community access management, and gift code features.

## 1) Data we collect
KingBot may store the following data:

### Discord data
- **User ID** (Discord user identifier)
- **Guild ID** used for server-related configuration and community access management
- **Language preference (FR/EN)** used for translations and messages in Discord
- **Guild membership state** for the official KingBot Community server when required to unlock specific features

### Kingshot-related data (provided by the user)
- **Kingshot Player IDs**:
  - **main ID**
  - **farm ID**
  - **farm2 ID**
  - **farm3 ID**
- **Kingshot profile data** used to help the user verify the linked account:
  - **nickname**
  - **region**
  - **center level**
  - **profile image / center image** when available
  - **last update timestamp**

### Gift codes & redemption data
- Gift codes added by users: **code**, optional **added date**, optional **expiration date**
- Redemption results per account/code: status such as
  **success**, **already**, **expired**, **server_busy**, plus the **popup/message** returned by the redemption process

### Ticket system data
- Ticket content and metadata: **message content**, **author**, **status**
  Used for support, bug reports, improvement requests, and **data deletion requests**

### Extra ID management data
- When a user leaves the official KingBot Community server, KingBot may temporarily store a scheduled cleanup state for **farm2** and **farm3** so those extra IDs can be removed later if the user does not return.

## 2) Why we collect this data (purposes)
We use the data to:
- Provide bot features (calculators, menus, translations, account tools)
- Link Kingshot IDs to the correct Discord user
- Display profile information so users can verify their account
- Manage gift codes and show redemption outcomes
- Manage feature access depending on membership in the official KingBot Community server
- Provide support through the ticket system and respond to requests
- Allow server-related configuration
- Remove extra Kingshot IDs when a user no longer meets the conditions required to keep them

## 3) Data sharing
KingBot does **not** sell personal data.
Data is not shared with third parties except:
- Discord (as part of using the Discord platform)
- The services required to run the bot (hosting / infrastructure)

## 4) Data retention
We keep data only as long as needed to provide the service:
- **Kingshot IDs / profiles / redemption results**: stored until the user requests deletion or stops using the bot for a long period
- **Extra IDs (`farm2` / `farm3`)**: may be removed automatically if the user leaves the official KingBot Community server and does not return within the configured delay
- **Tickets**: stored to handle support requests and history, then removed when no longer needed
- **Guild ID / guild membership state**: stored only as long as needed for the related server features

If you want a stricter policy, you can request deletion anytime via the ticket system.

## 5) Your rights (access / deletion)
You can request:
- Access to the data stored about you
- Correction of incorrect data
- Deletion of your data

**How to request:** open a ticket directly in the bot (Support / Ticket).
We may ask you to confirm ownership of the Discord account before deleting data.

## 6) Security
We take reasonable measures to protect stored data (access control, limited access to databases, etc.).
However, no system is 100% secure.

## 7) Contact
Support and privacy requests are handled **via the bot's ticket system**.
